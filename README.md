# Blinkit Data Analysis Dashboard

A Power BI dashboard designed to analyze **Blinkit's sales performance, customer ratings, product distribution, and outlet-level trends**. The project transforms retail data into an interactive dashboard that helps identify sales patterns, customer preferences, and opportunities for business optimization.

> **Project Status:** Completed  
> **Documentation Date:** June 2026  
> **Tool Used:** Microsoft Power BI  
> **Purpose:** Data Analysis & Visualization

---

## ?? Project Overview

The **Blinkit Data Analysis Dashboard** provides an interactive view of key business metrics across products and outlets. It combines sales, product, customer-rating, and outlet information into a single analytical dashboard.

The dashboard helps users understand:

- Overall sales performance
- Product and item-level performance
- Customer rating trends
- Consumer preferences based on fat content
- Sales distribution across product categories
- Outlet performance by size and location
- Differences between outlet types
- Outlet establishment trends over time

Interactive filters allow users to explore the data from different perspectives and identify important patterns.

## ?? Dashboard Features

### 1. Interactive Filters

The dashboard includes filters that allow users to analyze the data based on:

- Outlet Location Type
- Outlet Size
- Item Type

These filters make it easier to focus on specific business segments and compare their performance.

### 2. Outlet Establishment Trend

A time-series visualization tracks outlet establishment from **2012 to 2022**.

This provides an overview of how the number of outlets changed over the analyzed period.

### 3. Fat Content Analysis

The dashboard compares sales generated by:

- **Low Fat** products
- **Regular Fat** products

This provides insight into sales patterns across different product fat-content classifications.

### 4. Item Type Analysis

Sales are analyzed across multiple product categories to identify the categories contributing significantly to overall revenue.

The dashboard includes categories such as:

- Fruits & Vegetables
- Snack Foods
- Household Products
- Frozen Foods
- Dairy
- Other product categories

### 5. Outlet Size & Location Analysis

The dashboard compares outlet performance across different:

- Outlet sizes
- Location tiers

This helps examine the relationship between outlet characteristics, location, and sales performance.

### 6. Outlet Type Comparison

Different outlet types are compared using multiple metrics, including:

- Total Sales
- Number of Items
- Average Sales
- Average Rating
- Item Visibility

This provides a broader view of outlet performance beyond revenue alone.

## ?? Key Insights

Based on the analysis presented in the dashboard:

1. **Total sales exceed $1 million**, representing strong revenue generation across the analyzed products and outlets.

2. **Low-fat products contribute significantly to overall sales**, providing an interesting view of purchasing patterns based on product characteristics.

3. **Fruits & Vegetables and Snack Foods** are among the major contributors to product sales.

4. **Outlet size and location tier influence sales performance**, with medium-sized outlets in Tier 3 locations showing strong performance within this dataset.

5. **Supermarket outlets generate substantial sales volumes**, while grocery stores show comparatively higher item visibility.

These observations are specific to the dataset used in this project and should be interpreted within its scope and limitations.
